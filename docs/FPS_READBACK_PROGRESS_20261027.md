## Изменения общего пути CPU ↔ GPU

| Изменение | Что проверено | Граница результата |
|---|---|---|
| Providers физических данных GPU, алиасы A/C/E, поколения выделений | Реальные faults, частичные записи, Protect/commit/decommit и повторное выделение адреса | Низкие16МиБ с зеркалом7F исключены из экспериментального producer |
| Прямой IO/XMA | Резервирование страниц; атомарные диапазоны input/output/context; без блокировки памяти во время IO/декодирования | Реальные тела XFile/XMA с SDK Memory; качество кодека отдельно не проверяется |
| CPU-чтения графического потока | Пакеты через границу кольца, константы, шейдеры, resolve vertices, occlusion; адреса встроенных шейдеров | GPU upload заново открывает submission после ожидания памяти |
| Общий отложенный Vulkan readback | Текущее поколение, упорядоченная публикация, ограниченный пул, владение слотами и fences | Включается явно; только full/native FSI, не масштабированный render |
| Освобождение при ошибках | Поздние callbacks, failed/uncommitted copy, завершение GPU перед освобождением | ASan/UBSan и8 сценариев фактического teardown-кода |
| Быстрые обычные чтения CPU |6→0 выделений/чтение; IO, pending GPU, readonly и незакоммиченные страницы сохраняют защиту | Копирование без token только при непрерывно удерживаемой блокировке |
| Границы providers | Независимая модель4000 операций/>64000 запросов,512МиБ boundary | Внутри границ остаётся точная проверка пересечений |
| Минимальный префикс очереди | Лимиты количества/байтов, общие tickets, ошибки и12 реальных GPU-копий/8 faults | Новые копии остаются в staging вместо полного сброса очереди |
| Старейший подходящий слот | Известный ticket, successful retirement и occupied=false; ошибки/исключения/отсутствующая публикация | Собрано и GPU/ASan-проверено; последний кандидат ещё не запускался в игре |

Лимиты экспериментального игрового пула остаются64 слота/64МиБ. Добавлены
раздельные метрики ожидания CPU, давления пула, admission, переиспользования
подходящего слота и полного drain. Диагностика по-прежнему начинается не раньше
90 секунд от старта процесса.

   контроллера и HiDPI.
