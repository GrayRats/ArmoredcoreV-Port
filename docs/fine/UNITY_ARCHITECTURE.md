# Отложенная Unity-ветка

Статус: Исторический этап; Unity/C# не требуются для текущей Linux-цели.

**Подтверждено в отчёте:** Редактор 6000.6.6f1, URP 17.6.0; timing utility проверялась на девяти синтетических случаях.

**Ограничения:** Нет подтверждённого геймплея или PPC parity. Ошибки Package Manager требуют отдельной проверки при возобновлении Unity.
